# Guia de contribucion

Gracias por tu interes en contribuir al proyecto Tienda TECSUP.

## Como contribuir

1. Revisa el proyecto y sus funcionalidades.
2. Identifica oportunidades de mejora.
3. Reporta errores mediante Issues en GitHub.
4. Propone soluciones mediante Pull Requests.

## Recomendaciones

- Mantener el codigo ordenado.
- Utilizar nombres descriptivos.
- Documentar los cambios realizados.
- Verificar el funcionamiento antes de proponer modificaciones.
