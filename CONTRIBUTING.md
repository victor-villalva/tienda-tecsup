# Guía de contribución

Gracias por tu interés en contribuir al proyecto Tienda TECSUP.

## Cómo reportar un error

1. Identifica el error encontrado.
2. Describe los pasos para reproducirlo.
3. Explica el resultado esperado y el resultado obtenido.
4. Reporta el problema mediante Issues en GitHub.

## Cómo proponer una mejora

1. Identifica una oportunidad de mejora.
2. Describe el cambio que propones.
3. Crea una rama para realizar los cambios.
4. Registra los cambios mediante un commit.
5. Envía un Pull Request explicando la mejora realizada.

## Checklist para enviar un Pull Request

Antes de enviar un Pull Request, verifica lo siguiente:

- [ ] El código está ordenado y es fácil de entender.
- [ ] Los cambios cumplen el objetivo propuesto.
- [ ] Se verificó el funcionamiento de los cambios.
- [ ] No se afectaron las funcionalidades existentes.
- [ ] Se documentaron los cambios realizados.
